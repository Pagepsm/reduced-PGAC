# 大規模離散時間システムに対する低次元方策勾配適応制御

**Reduced-Order Policy Gradient Adaptive Control for Large-Scale Discrete-Time Systems**

未知の線形システムを運転しながら学習する間接型PGACに、初期状態データの特異値分解（SVD）による次元削減を組み込みました。モデル推定と方策勾配計算を共通の低次元空間で行うことで、制御器の更新に必要な計算を減らす方法を研究しています。

100状態・4入力の合成系で、24次元に縮約した制御器を全状態のPGACと比較しました。**10試行すべてで24次元の最終最適性ギャップが小さく**、平均値はFullの **0.17428** に対して24次元で **0.07310** でした（58.1%減）。各手法の中央値は **0.1399**、**0.0648** です。制御器側のオンライン計算時間は **9.43から0.184 ms/step** となり、計算時間は約51分の1になりました。

## 研究で取り組んだこと

間接型PGACは、運転中の状態と入力から未知のシステム行列を逐次推定し、推定モデル上の方策勾配でフィードバックゲインを更新します。状態数が増えるほど、推定する行列が大きくなり、十分に励起されていない状態方向も回帰に含まれる点が課題です。

そこで、初期状態データの主要な変動方向をSVDで選び、射影行列を固定して学習を行う構成にしました。100状態・4入力を24状態に縮約すると、回帰ベクトルは **104次元から28次元**、推定するモデルパラメータは **10,400個から672個** に減ります。

評価用の合成プラントには、強く励起される12方向、制御上重要な12方向、弱く励起される76方向を設けました。**最初の24方向に状態変動と制御上の重要度を集め、縮約次元による性能の違いを調べる設計**です。[実験方法](docs/experiment-design.md)では、固有値や群別の入力係数・外乱・評価重みを具体的に説明しています。

## 現在の成果と次の研究

10試行の数値実験では、比較した縮約次元 $`n_r\in\{12,20,24,48,80\}`$ のうち、24次元が制御性能と計算時間のバランスで良好でした。Fullとの対応比較で10勝0敗となり、**正確符号検定（両側）で $`p=0.001953125`$** を得ました。データ共分散行列の最小特異値と条件数も、24次元ではFullより良好な値になりました。[結果と考察](results/README.md)に図を掲載しています。

次は、縮約次元を選ぶ指針、射影誤差を含む高次元系の安定性・性能解析、異なるプラントや実データによる検証を進めます。

## 先行研究

本研究は、Zhao・Chiuso・Dörflerの間接型PGACと、Sadamoto・Chakrabortty・Imuraの状態データSVDによる低次元強化学習制御を出発点としています。先行研究の役割と本研究の位置づけは[研究の全体像](docs/research-overview.md)に整理しました。
